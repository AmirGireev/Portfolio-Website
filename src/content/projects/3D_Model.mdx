## About the Project
For this project
I created a realistic 3D living room in Maya based on real-world photo references.
To bring the model to life, I set up a studio environment and
applied Arnold shaders, incorporating UV unwrapping and PBR materials for realistic 
surface properties. The final scene was lit using an HDRI-based IBL setup combined
with supplementary lighting. The final 1080p image was rendered using Arnold
 with sample settings and denoising.
