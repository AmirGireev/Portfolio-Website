## About the Project

A prototype website developed step-by-step from brainstorming to a final review.
For that we used techniques like Crazy 8s, personas, use case diagrams, scenarios, class diagrams, and sequence diagrams.
Focused on learning Django basics, especially Admin-User connections.
You can type "Fashionalex" in the search bar to find an account. You can also add your own pictures or pictures of other accounts to your own "Virtual Warderobe".
The usecase for this website would be to get fashion inspiration from other users or the website itself using its own search engine.
There were many other ideas I wanted to implement such as a comment section, likes, the search engine working properly, a login...
