## About the Project

Klothes is a full-stack web app built with Django and SQLite. 
It features a complete user authentication system, allowing users to create accounts,
 find outfits via filter or keyword search, and save their favorite looks to a personal virtual wardrobe.
Outfit images are seamlessly managed and served from the cloud using Cloudinary.

The data model uses one-to-one, one-to-many, and many-to-many relationships (users, profiles, outfits, and saved wardrobes). 
Search runs through the Django ORM with combined queries, and content is managed through the Django admin. 
The project includes automated tests for search and the wardrobe.
