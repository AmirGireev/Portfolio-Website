## About the Project
FolderCity shows a code base as a 3D city: folders become platforms and files become buildings.
Built with React Three Fiber and a FastAPI backend, it analyzes imports, API routes and
database access with tree-sitter.
The code is also checked for lint and rule findings such as hard-coded secrets and risky calls, 
and affected buildings are marked in the city.
An AI assistant based on embeddings and pgvector answers questions
about the code, checks every reference and flies the camera to the right building.
A guided tour mode helps to present a repo.
