## About the Project

Currently developing a dynamic 2D parkour game, featuring a custom C# character controller built for fluid "game feel"
(coyote time, jump buffering, dashing) and a unique projectile-teleportation mechanic.

Programmed a speedrunning framework with a level timer, high-score leaderboards, and checkpoint respawns.

Implemented a look-ahead camera, edge-detecting enemy AI, and an
UI that handles both keyboard and gamepad inputs.
