## About the Project

I am currently developing a dynamic 2D jump-and-run parkour game in Unity, with a technical focus on character movement and overall "game feel". 

I programmed a custom 2D character controller in C#. The game features platforming mechanics designed to make movement smooth, precise, and satisfying to play.

Implemented platforming feel components like coyote time, jump buffering, variable jump heights, and wall-sliding/jumping.
Developed a follow camera with look-ahead functionality.
Designed using Unity's Tilemap system with colliders and custom hazards (spikes, checkpoints, and moving enemies).
